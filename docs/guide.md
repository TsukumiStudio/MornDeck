# 画面と設定の詳細

[README](../README.md) の続きです。画面の操作・設定・ファイルについて、詳しく説明します。

## コマンド

| コマンド | できること |
| --- | --- |
| `mdeck` | 画面を開きます。サーバーが動いていなければ、先に起動します |
| `mdeck api '<json>'` | API を 1 回呼びます ([API と MCP](api.md)) |
| `mdeck mcp` | stdio の MCP サーバーとして動きます |
| `mdeck server` | サーバーを前面で起動します。ふつうは `mdeck` が起動するので、使う必要はありません |
| `mdeck --version` | 版を表示します |

サイドバーには、上から「MornDeck vX」(サーバーの版)、「⚙ Config (c)」「✕ Exit (e)」、タブ、「+」が並び、一番下に使用量が出ます。

## キーボード

`F12` (Mac の内蔵キーボードでは fn+F12) を押すと、サイドバーを操作できるようになります。操作中は、画面全体が黄色い枠で囲まれます。`F12` はタブの中へは送りません。

| キー | できること |
| --- | --- |
| `↑` `↓` / `k` `j` | 項目を選びます。タブを選ぶと、そのタブが画面に出ます |
| `Enter` | 選んだ項目を実行します。タブなら、そのタブに戻って作業を続けます |
| `→` | タブのメニューを開きます。Config・Exit・+ では `Enter` と同じです |
| `c` / `e` | Config を開きます / 画面を閉じます (タブは動いたまま残ります) |
| `F12` | サイドバーの操作をやめます |

Config やタブのメニューでは、値を `←` / `→` で変えます。`Enter` は、文字の入力と、更新・導入・削除などの操作にだけ使います。閉じるときは、一番下の「閉じる (F12)」を選ぶか `F12` を押してください。`←` や `Esc` では閉じません。文字の入力中は、`←` / `→` でカーソルが動き、`Enter` で決定、`F12` で入力をやめます。

## Config

| 項目 | 説明 |
| --- | --- |
| 更新を確認 | 新しい版があるかを確かめます。見つかると「更新を反映」に変わり、`Enter` で入れ替えます |
| フック | Claude Code・Codex・GitHub Copilot のフックの版を表示します。`Enter` で導入・更新します |
| 見た目 › サイドバーの幅 | `←` / `→` で変えます |
| 通知 › 完了した時の通知音 | `←` / `→` で、「なし」か Mac のシステムの音を選びます。選ぶと、その音が鳴ります |
| 通知 › 完了した時のポップアップ | macOS の通知を出すかどうかを、`←` / `→` で切り替えます |
| 通知 › 通知先のあるタブは非通知 | オンにすると、通知先 (webhook) を決めてあるタブでは、通知音もポップアップも出しません |
| 通知先 (webhook) | 行の上で `←` / `→` を押して「編集」か「削除」を選び、`Enter` を押します。「+ 通知先を追加」では、名前 → URL の順に入力します。`Authorization` などのヘッダーを付けたいときは、API の `add_webhook` を使ってください |

通知音とポップアップが出るのは、画面に出ていないタブのエージェントが返事を書き終えたときだけです。設定は `~/.mdeck/config.json` に残ります。

## タブのメニュー

| 項目 | 説明 |
| --- | --- |
| タブ名 | `Enter` で入力します。空にすると名前を外します |
| 通知先 | `←` / `→` で、登録してある通知先から選びます |
| AutoYes | 実行の確認に、自動で Yes と答えます (下の「AutoYes」を見てください)。`←` / `→` でオン・オフを切り替えます |
| タブを削除 | 確認で「削除する」を選ぶと、タブを閉じます。中のエージェントも終わります |

エージェントが返事を書き終えたまま誰も見ていないタブには、サイドバーに「● 未読」と出ます。タブを画面に出すか、API で返事・画面・選択肢を読むか、文字を送ると、未読は消えます。

## マウス

- サイドバーとポップアップの項目は、マウスを乗せると反応します。ポップアップでは、乗せた項目が選ばれます。
- 左クリックすると、Config・Exit・+ を実行します。タブなら、そのタブに戻って作業を続けます。ポップアップの項目は実行し、値の行は次の値に進めます。
- 右クリックすると、タブのメニューが開きます。ポップアップの値の行は、前の値に戻します。
- ポップアップの外をクリックすると、ポップアップが閉じます。ポップアップの上でホイールを回すと、選ぶ項目が上下に動きます。
- サイドバーの境目をドラッグすると、サイドバーの幅が変わります。
- 端末の中をドラッグすると文字を選べて、離すとクリップボードに入ります (サイドバーの文字は入りません)。ホイールを回すとスクロールします。claude のようにマウスを使うアプリが動いているときは、マウスの操作をそのアプリに渡します。
- ssh でつないでいるときのコピーは、端末アプリが OSC 52 に対応している場合だけ使えます。Terminal.app は対応していません。

## AutoYes

AutoYes をオンにしたタブでは、画面を 0.3 秒ごとに確かめます。カーソルの付いた Yes / No だけのメニューが出たら、最初の Yes を選びます。claude の「Do you want to proceed?」や、codex の「Would you like to run the following command?」などが対象です。

- ファイルの削除や push の確認にも Yes と答えます。オンにするのは、任せてよい作業のタブだけにしてください。
- 質問 (AskUserQuestion)、計画の承認、Yes / No 以外の選択肢には答えません。
- Yes を押したことは、`events.log` と webhook (`auto_yes`) に残ります。答えなかったメニューも `events.log` に残ります。
- オンにしたまま MornDeck のサーバーを起動し直しても、オンのまま続きます。

## 使用量

サイドバーの一番下に、claude と codex は週ごと、copilot は月ごと (プレミアムリクエスト) の使用量を出します。

- 「Claude +2d12h」は、期間の経過に比べて 2 日 12 時間分使いすぎていることを表します。`-` が付いていれば、まだ余裕があります。
- ゲージの塗りが使った量を、`│` が期間の中の今の位置を表します。

| エージェント | 使用量の読み方 | 読み直す間隔 |
| --- | --- | --- |
| claude | キーチェーンにある Claude Code のトークンで、使用量の API を呼びます | 5 分 |
| codex | `~/.codex/sessions` の最新の記録を読みます | 1 分 |
| copilot | `copilot login` の認証情報 (キーチェーンの `copilot-cli` か `~/.copilot/config.json`) で、GitHub の内部 API を呼びます | 5 分 |

- キーチェーンを初めて読むときに、macOS の許可ダイアログが出ることがあります。
- ssh で入ったセッションからは、キーチェーンを読めません。そのため、ssh から `mdeck` や `mdeck mcp` を起動したときは、MornDeck.app を `open` で起動して、サーバーを Mac の画面側 (ログインしているセッション) で動かします。このとき、ウィンドウや Dock のアイコンは出ません。
- Mac の画面側に誰もログインしていないときは、ssh のセッションでサーバーを起動します。この場合、claude と copilot の使用量は出ません。出ない理由は、`events.log` の `usage` の行に残ります。
- copilot のトークンは、サーバーが起動している間に 1 回だけ読みます。あとから `copilot login` したときは、サーバーを起動し直してください。
- copilot の使用量は GitHub の内部 API で取っているので、プランや API が変わると出なくなることがあります。

## ファイル

ファイルはすべて `~/.mdeck/` に置きます。環境変数 `MDECK_SOCK` でソケットの場所を変えると、ほかのファイルもソケットと同じ場所に置きます。

| ファイル | 中身 |
| --- | --- |
| `mdeck.sock` | API のソケットです |
| `tabs.json` | タブの並び・名前・通知先 (owner)・作業ディレクトリ・会話 ID・AutoYes と、サイドバーの幅です |
| `config.json` | 通知音・ポップアップ・非通知の設定です |
| `webhooks.json` / `owner_webhooks.json` | 全体の通知先 / owner ごとの通知先です |
| `events.log` | 起きたことの記録です。API の呼び出しと結果、フック、状態の変化、AutoYes、webhook、設定の変更、サーバーの起動し直しが残ります。ヘッダーの値は伏せ、長い文字列は途中で切ります。10MB を超えると `events.log.1` に移します |
| `webhook.log` | webhook を送った結果 (HTTP ステータスや curl のエラー) です |
| `hook.log` | サーバーに届かなかったフックです |
| `mcp.log` | MCP の呼び出しです |
| `mdeck.log` | サーバーのエラー出力です |

タブの中では、環境変数 `MDECK_TAB` (タブの番号) と `MDECK_SOCK` が使えます。

## 困ったとき

| 起きていること | 確かめること |
| --- | --- |
| `F12` が効かない | 端末アプリやシステムの設定が `F12` を使っていないかを確かめてください |
| サイドバーにエージェントの状態が出ない | Config の「フック」が「最新です」になっているかを確かめて、エージェントを起動し直してください。届かなかったフックは `hook.log` に残ります |
| 更新したのに版が変わらない | 古いサーバーが動いたままです。`pkill -f 'mdeck server'` を実行してから、`mdeck` を開き直してください |
| `mdeck` がつながらない | `mdeck.log` を見てください |
| `open_tab` が `timed_out` で返る | フックが入っていません (返事に `hint` が付きます)。Config の「フック」から導入してください |
| `open_tab` が `blocked` で返る | エージェントが起動時の確認画面 (フォルダを信頼するかどうかなど) で止まっています。`options` を見て、`choose` で答えてください |
| `send` が `busy` / `not_ready` で返る | 作業中なら `wait` で待ってください。起動待ちなら、`get_choices` で選択肢を見て `choose` で答えてください |
| webhook が届かない | `test_webhooks` で HTTP ステータスを確かめてください。これまでに送った結果は `webhook.log` に残っています |
| AutoYes が答えずに止まった | `events.log` の `auto_yes` の行に、押したかどうかと、答えなかった理由が残っています |
| MCP が応答しない | `mcp.log` で、呼び出しが届いているかを確かめてください。ssh でつなぐときは、`-t` を付けないでください |
